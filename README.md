# Печатные издания — практическая работа UML

Готовое консольное приложение на Python 3.9+. Внешние библиотеки не нужны.

## Запуск

Из каталога проекта:

```bash
python3 main.py
```

Меню: 1 — добавить, 2 — удалить по индексу, 3 — показать, 4 — сравнить, 0 — выйти. Индексы начинаются с нуля. Данные хранятся до завершения сеанса.

## Как разбирать код

1. `models/validation.py`: диапазоны, проверка типов и значений.
2. `models/printed_edition.py`: общие поля и специальные методы Python.
3. `models/magazine.py` и `models/book.py`: наследование и `super()`.
4. `models/textbook.py`: наследование от книги.
5. `ui/menu.py`: повторный ввод, список базового типа, операции меню.
6. `main.py`: точка входа.

Все классы имеют параметры по умолчанию, `__eq__`, `__hash__`, `__str__`. Равенство учитывает точный тип и все поля. Не изменяйте поля объектов, используемых как ключи словаря или элементы множества.
